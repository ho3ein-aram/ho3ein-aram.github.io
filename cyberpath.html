🧪 لابراتوار امن

تمرین را به محیط جدا از سیستم واقعی منتقل کن؛ هدف، یادگیری رفتار و دفاع است.

۱) اصل جداسازی

برای تمرین از VM، شبکهٔ Host-only، Docker، CTF و اپ‌های عمداً آسیب‌پذیر استفاده کن. دادهٔ واقعی، حساب‌های واقعی و سامانه‌های عمومی را وارد آزمایش نکن.

$ mkdir -p ~/cyber-lab/{notes,pcaps,logs}
$ echo "authorized-lab" > ~/cyber-lab/README.txt
$ printf "scope: localhost only\n" >> ~/cyber-lab/README.txt

۲) تمرین تحلیل دفاعی

یک درخواست ساده را در محیط محلی ثبت کن، لاگ بگیر، شاخص‌ها را استخراج کن و سپس برای همان رفتار یک کنترل دفاعی طراحی کن. این حلقهٔ «مشاهده → فرضیه → آزمایش → تشخیص» پایهٔ خوبی برای Security Engineering است.

local-log-analysis.pyPython
import re
from collections import Counter

log = """GET /index HTTP/1.1
GET /admin HTTP/1.1
GET /index HTTP/1.1
GET /missing HTTP/1.1"""

paths = re.findall(r"GET\s+(\S+)", log)
counts = Counter(paths)

for path, count in counts.most_common():
    print(f"{path:12} {count}")

۳) نمونهٔ کدنویسی امن

برای یادگیری AppSec، اول نسخهٔ ناامن را در آزمایشگاه فرضی درک کن، سپس نسخهٔ امن را پیاده‌سازی کن.

node-security.jsNode.js
const express = require("express");
const app = express();

app.use(express.json());

app.get("/user", (req, res) => {
  const id = Number(req.query.id);
  if (!Number.isInteger(id) || id < 1) {
    return res.status(400).json({ error: "invalid id" });
  }
  res.json({ id });
});

app.listen(3000);
