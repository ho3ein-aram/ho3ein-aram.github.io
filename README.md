# Hossein Personal Web App

Dark, Telegram-inspired personal web app built with plain HTML/CSS/JS.

## Run
Open `index.html` in a browser or upload the folder to any static hosting/cPanel public_html.

## Content
Settings → مدیریت محتوا lets you edit the basic profile links/text. Posts are stored in the browser's localStorage in this static version.

## Important
The AI screen is a UI placeholder until a real AI API/backend is connected. For public multi-device persistent posts/profile management, connect a backend/database later.
