GitHub Folder Uploader

آپلود مستقیم پوشه به Repository با یک Commit واقعی
توکن فقط در همین صفحه در حافظه استفاده می‌شود و در localStorage ذخیره نمی‌شود.
مثال: siteatlascode/siteatlascode.github.io
پوشه را انتخاب کن ساختار زیرپوشه‌ها حفظ می‌شود.
مثلاً پوشه MUNITOS با مقصد apps به apps/MUNITOS/... تبدیل می‌شود. با خاموش‌کردن این گزینه، محتویات مستقیماً داخل مقصد می‌روند.
